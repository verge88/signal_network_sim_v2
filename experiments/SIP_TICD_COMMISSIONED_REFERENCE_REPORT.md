# TICD: индивидуальная опора при вводе в эксплуатацию и смена режима

## Постановка
Исходные модели и нормальные опоры заморожены по артефакту успешного Actions #45461470242. Максимум FPR в независимом исследовании составил 3,076% для выбранного основного детектора и 3,103% для гибридного. Согласованность блоков не исключила длительные фоновые смещения. Сохраняются I1, I2, D, история, ролевое взвешивание, усечённый S48, быстрый последовательный накопитель, длинная условная статистика с блочной поддержкой, предупреждения и независимый синтетический аудит. Не производится упрощение.

## Индивидуальная опора
Номера узлов в различных случайных установках не считаются идентификаторами одной физической системы. Для каждой имитируемой установки формируется отдельная двухчасовая чистая запись ввода в эксплуатацию. Топология, постоянные характеристики узлов и фиксированные неоднородные коэффициенты потерь каналов (равномерно 0,8–1,2) общие для этой записи и последующего эксплуатационного прогона. При вводе в эксплуатацию используются независимые потоки случайности трафика, транзакций и CU, отсутствуют атаки; четыре заранее заданных режима потерь (1, 5, 10, 25) по 90 интервалов. Эта запись не является частью эксплуатационной тестовой трассы. Принадлежность записи конкретной установке — ключ соответствия инвентаря, а не числовой предиктор. Не используются метки или истинные значения потерь при принятии решения. Доверенная нормальность записи ввода в эксплуатацию — предпосылка метода, а не результат работы детектора.

Для каждого узла на отдельно наблюдаемых данных оценивается среднее знакового стандартизованного остатка предыдущей условной модели с весами по корню информационного масштаба; не менее 120 допустимых наблюдений, усадка к нулю с псевдообъёмом 120. Для диапазонов наблюдаемой вероятности потерь при не менее 25 наблюдениях оценка усаживается к индивидуальной общей опоре с псевдообъёмом 100. Абсолютная величина поправки не превышает 0,75 стандартизованной единицы. Профиль фиксирован до обработки эксплуатационной записи; онлайн-подстройка по подозрительному трафику не предусмотрена. В окнах 96 и 144 интервалов рассчитывается дополнительная накопленная статистика центрированного остатка. Масштабы по роли определяются только на отдельных чистых обучающих установках. Доля новой индивидуализированной оценки в смеси с прежней длинной статистикой составляет 0, 0,5 или 0,75. В каждом варианте вклад прежней длинной статистики строго положителен, исходные инварианты и прежний короткий накопитель сохраняются. При отсутствии достаточного профиля возвращается прежняя длинная статистика (общий порог выбранной модели может отличаться от замороженного контрольного детектора).

## Испытания
30 сценариев: 25 ранее использованных и пять дополнительных — чистая смена потерь, чистая смена нагрузки, слабые воздействия 0,25% и 0,5% на фоне совместной смены режимов, компрометация REDIRECT при совместной смене режима. Смена задаётся на границах 90-интервальных фаз; номинальные потери изменяются в пределах 2–25-кратных исходных значений, нагрузка в пределах 0,65–1,5 исходного уровня. Во всех 30 сценариях присутствует фиксированная неоднородность коэффициентов потерь каналов; номинальные обозначения ×25 и др. не означают строго одинаковых эффективных потерь каждого канала. Прежние детекторы оцениваются на тех же изменённых данных. Отдельный синтетический аудит сохраняет существующую модель, не подстраивается по фактическим изменениям транспортного режима. 32 обучающих + 48 калибровочных + 90 разработочных (30×3) + 180 независимых тестовых (30×6) = 350 эксплуатационных двухчасовых реализаций и 350 отдельных чистых записей ввода в эксплуатацию, 2 772 000 строк ведомых в двух наборах, из них 712 800 эксплуатационных тестовых. Дополнительно отдельная контрфактическая проверка. Новые seed установок >=201001. 96 кандидатов: 2 окна × 3 веса × 2 схемы нормирования × 4 бюджета × 2 правила робастной калибровки. Порог предупреждения калибруется с бюджетом 0,35%, суммы бюджетов сильной тревоги <=0,8% на нормальной калибровочной выборке. Условия выбора: максимальные FPR <=1%, FWR <=0,5%, не более 3 п.п. ухудшения средней полноты слабых, высокопотерных, нативных, новых переменных и аудиторских сценариев по сравнению с замороженными контролями. Если кандидатов нет, выбор по заранее заданной штрафной полезности с указанием невыполненных целей. Две замороженные модели, две заново откалиброванные без индивидуальной поправки и две выбранные на разработке оцениваются на общей итоговой выборке. Индивидуальные опоры рассчитываются из отдельных чистых записей тестовых установок, а не из тестового эксплуатационного трафика. Это условная проверка переноса на новую установку с доверенной процедурой ввода, не zero-shot. Парные bootstrap и Wilcoxon/Holm по десяти заранее заданным сравнениям, включая смену режима. Аудит префиксной каузальности, отсутствия меток при применении, точного возврата прежней статистики при нулевом весе или отсутствии профиля, равенства решений для идентичных наблюдений, повторной загрузки.

## Ограничения
Чистый период ввода в эксплуатацию и независимая телеметрия предполагаются доверенными; устойчивость к загрязнённой опоре отдельно не доказана. Изменены коэффициенты потерь и нагрузки, а не структура графа, не моделируется смена состава узлов. Нет прямого наблюдения фактических потерь SIP, независимый аудит остаётся синтетическим, ведущий SBC не моделируется как полноценно скомпрометированный узел. Проверка на реальной сети отсутствует. Не заявляется универсальная гарантия FPR или положительный результат до выполнения эксперимента.
