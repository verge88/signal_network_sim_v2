# Исследование накопления слабых отклонений ACK в TICD

**Версия исследования:** 24 ноября 2026 года.  
**Код детектора:** `sip/ticd_causal_ack.py`.  
**Эксперимент:** `experiments/retrain_ticd_causal_ack.py`.  
**Воспроизводимое обучение:** `.github/workflows/sip-ticd-causal-ack.yml`.

## 1. Цель исследования

Исходная `LossConditionedTICD` корректирует физические
рассогласования SIP ACK/200 с учётом фоновых потерь и типов
узлов. В эксперименте с потерями ×10 её чувствительность
к статистической маскировке компрометации составила 58,97%
при FPR 1,38%. На независимых доброкачественных прогонах
с потерями ×15 отмечался FPR 1,625%, то есть ограничение
в 1% в новых условиях не гарантируется.

Настоящий этап проверяет, может ли накопление
**слабых, но устойчивых** нарушений физического замыкания
повысить полноту обнаружения, не приводя к значительному
росту ложных тревог.

## 2. Архитектура

Для узла `i` и интервала `t` измеряется доступный
мастеру скорректированный физический дефицит:

`r_i(t) = max(0, 1 - cu_dcr_transit_i(t) - cu_combined_loss_prob_i(t))`.

Он рассчитывается через независимые транзитные
счётчики SIP ACK и 200 OK с учётом наблюдаемого
приближения потерь канала СУ; это **статистическое
отклонение**, а не безусловный инвариант RFC 3261.
Оригинальный класс `PhysicalClosureTICD` и
предыдущая `LossConditionedTICD` при этом сохраняются
без изменения обученных параметров.

Для трёх масштабов времени — 6, 16 и 32 интервала
по 20 с — оценивается экспоненциальное среднее:

```
R_i^(h)(t) = alpha_h * r_i(t)
             + (1 - alpha_h) * R_i^(h)(t-1),
alpha_h = 2 / (h + 1).
```

В момент `t` используются **только записи текущего и
прошлых интервалов данного узла**, а не будущие
наблюдения или величины из незнакомого тестового пакета.

По референтной доброкачественной выборке вычисляются
условные квантили `Q_{0.99}(R | B(L), node_type)`.
Здесь `B(L)` — группа наблюдаемой оценки потерь
канала СУ, `node_type` — известный тип сетевой
функции. Метки атак, скрытая истинная отчётность
`gt_*` и метки компрометированного состояния
при этом **не участвуют**.

Оценка кандидата:

```
S_i(t) = max[
    S_LossConditionedTICD_i(t),
    lambda * R_i^(h)(t) / max(0.001, Q_0.99[R | B(L), node_type])
].
```

Рассматриваются `h=6,16,32` и коэффициенты
`lambda=0.7` или `1.0`. Кандидат и коэффициент
выбираются только на отдельной разработочной
**имитационной** выборке; сама модель
одноклассовая, обучается только на нормальных
значениях.

## 3. Разделение выборок

| Назначение | Seed и содержание |
|---|---|
| Обучающая норма | 8101–8502: по два прогона для потерь ×1, ×3, ×5, ×10, ×15 |
| Проверочная норма | 8601–9002: отдельные два прогона для каждого режима |
| Разработка | 9101–9402: обычные атаки, слабое воздействие при ×10 и ×15, правдивая отчётность |
| Независимый тест | 10101–10703: по три новых прогона каждого из семи режимов |

**Независимый тест** проверяет обычные атаки,
слабую компрометацию при ×5, ×10 и ×15,
правдивую отчётность нарушителя, полностью
доброкачественный трафик при ×7,
а также *экстраполяционный* режим ×20,
который отсутствует в обучающей норме.

Порог определяется по наибольшему из 99-х
процентилей пяти нормальных проверочных
режимов. Тестовые метки и распределения не
используются для обучения, выбора варианта
или определения порога.

## 4. Контроль корректности

Проверяются следующие свойства:

- одинаковая оценка наблюдения вне зависимости
  от его расположения и соседей в тестовом пакете
  при уже вычисленной каузальной истории;
- невозможность влияния изменения будущих
  значений физического ACK-дефицита на ранее
  сформированные экспоненциальные средние;
- отсутствие общих seed между обучением,
  валидацией, разработкой и итоговым тестом;
- успешная сохранность и повторная загрузка
  модели и настроенного порога;
- сохранение контрольной суммы
  `e455d66eef30d9399ba3beefc36ad2a4a7e2fac0684aa1ae405a30a2371af9a7`
  реального LTE-A SIP-архива, применённого
  исключительно для частичной калибровки
  нормального распределения INVITE/ACK/BYE.

## 5. Ограничения

Это по-прежнему **имитационные** эксперименты.
Внешние натурные PCAP не дают одновременной
доверенной телеметрии SIP-прокси, наблюдений
полного тракта и независимой истинной
разметки компрометации. Отдельные 20-секундные
записи внутри имитационного прогона не являются
независимыми измерениями; основные
единицы повторения — самостоятельные seed.

Важная эксплуатационная оговорка:
`cu_combined_loss_prob` измеряет/моделирует
потери контрольного пути, которые не обязаны
совпадать с потерями SIP на реальном транзите.
Результаты на синтетической связанной модели
не устанавливают полноту или FPR метода на
реальных телефонных сетях.

## 6. Фактические результаты первого независимого испытания

[GitHub Actions #45247020460](https://github.com/verge88/signal_network_sim_v2/actions/runs/45247020460)
завершился успешно. На выборке для разработки выиграл
вариант `causal_short_w0p7` — экспоненциальное среднее
с параметром длины 6 интервалов и относительным
коэффициентом 0,7. Использованы 39 600 нормальных
обучающих и 39 600 нормальных проверочных
наблюдений (по 10 разным seed в каждом наборе),
а также семь неучаствовавших в настройке наборов
по три независимых имитационных прогона.

| Имитационный сценарий | Полнота старой TICD (%) | Полнота новой TICD (%) | FPR старой (%) | FPR новой (%) |
|---|---:|---:|---:|---:|
| Стандартные атаки | 69,80 | 69,80 | **0,794** | 1,969 |
| Слабое перенаправление, потери ×5 | 92,52 | **99,95** | 0,623 | 0,694 |
| Слабое перенаправление, потери ×10 | 84,70 | **99,03** | 1,150 | 1,180 |
| Слабое перенаправление, потери ×15 | 83,59 | **95,68** | 1,201 | 1,190 |
| Правдивая отчётность | 99,75 | 100,00 | 0,566 | 0,637 |
| Нормальный трафик, потери ×7 | Не определяется | Не определяется | 1,170 | 1,279 |
| Нормальный трафик, потери ×20 | Не определяется | Не определяется | 1,616 | 1,658 |

**Полнота именно статистической компрометации**
в синтетических сценариях: при потерях ×5 —
с 78,02% до **99,85%**, при ×10 — с 54,12%
до **97,30%**, при ×15 — с 51,64%
до **87,01%**.

Проверки сохранения/повторной загрузки
`ticd_causal_ack_model.pkl`, стабильности при
изменении состава пакета и отсутствия
влияния будущих наблюдений на каузальную
историю выполнены успешно.

**Отрицательный результат:** повышенная полнота
достигнута ценой увеличения FPR в стандартном
сценарии с 0,794% до **1,969%**. Поэтому
необходимо дополнительное взаимное подтверждение
мгновенного и накопленного сигналов: первый
положительный результат не означает, что эта
архитектура готова к принятию без ограничений.

## 7. Вторая конструкция: согласование физического и накопленного сигналов

Добавлен модуль `sip/ticd_corroborated_causal.py`:
```
S_gated(t,i) = max(
    S_instant(t,i),
    min(S_persistent(t,i), S_instant(t,i) / g)
)
```

где `g` — коэффициент согласованности
с мгновенным независимо наблюдаемым физическим
отклонением. При слишком слабом мгновенном
сигнале большие значения накопленной
аномалии не должны автоматически приводить
к тревоге. В отличие от изменения обучаемых
параметров модели, это изменение правила
объединения двух **уже обученных и замороженных**
компонент.

Значения `g` из набора
`0.3,0.4,0.5,0.6,0.7,0.8,0.9`
проверяются на новой отдельной имитационной
разработочной выборке; конечный порог
настраивается только на свежей доброкачественной
валидации. Финальный тест использует новые
seed `12101–12703` (ни один не совпадает
с ранее использованными), отдельно
проверяет слабое перенаправление при
высоких потерях и режим нормальных потерь ×20.

Конструкция разработана после обнаружения
увеличенного FPR на предыдущем тесте.
Это допустимый анализ инженерного недостатка,
но нельзя повторно использовать тот старый тест
для несмещённой оценки новой гипотезы —
поэтому для следующего этапа
выделены **совершенно новые финальные прогоны**.
