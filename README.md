# Signal Network Sim v2

Исследовательский симулятор сигнальных сетей **SS7, Diameter и SIP**. Это очищенная версия [signal_network_sim](https://github.com/verge88/signal_network_sim) без реализации 5G SBA, с сохранением кода моделирования, обучения, экспериментов, графического редактора топологий и регрессионных тестов.

## Структура

- `ss7/` — научная модель `fix.py`, совместимый интерфейс `canonical.py`, историческая модель `ss7_simulator_v7.py` (используется редактором топологий), обучение и графики.
- `diameter/` — генератор Diameter, обучение и многосидовые прогоны.
- `sip/` — генератор SIP, TICD и альтернативные модели, многосидовые прогоны.
- `scientific/` — общие научные контракты.
- `experiments/` — контроль исходных результатов, манифесты прогонов и сравнение метрик.
- `gui/` — редактор топологий, запуск экспериментов и просмотр результатов.
- `tests/` — регрессионные тесты и проверки научных контрактов.

## Подготовка

Рекомендуется Python 3.11+ и отдельное виртуальное окружение. Базовые зависимости перечислены в `requirements.txt`. Для запуска нейросетевых моделей дополнительно требуется PyTorch (подходящий пакет зависит от процессора/GPU).

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m gui
```

## Эксперименты

```bash
python -m experiments.baseline run --protocol ss7 --seeds 42
python -m experiments.baseline run --protocol diameter --seeds 42
python -m experiments.baseline run --protocol sip --seeds 42
```

Файлы наборов данных (`*_dataset_*.csv`) намеренно не перенесены: они являются результатами генерации и могут занимать сотни мегабайт. Перед обучением сформируйте нужные данные с помощью соответствующих модулей симуляции и укажите путь к CSV.

**Важно:** научный источник истины для SS7 — `ss7/fix.py` через `ss7/canonical.py`. Старый `ss7_simulator_v7.py` оставлен для совместимости GUI; результаты этих реализаций не следует смешивать без отдельной проверки.

## Происхождение

Исходники перенесены из [verge88/signal_network_sim](https://github.com/verge88/signal_network_sim), коммит `117282e355ceb6486cc879df2467172fbc155942`. Исключены 5G SBA, тесты 5G, временные кэши, резервные копии, сгенерированные датасеты, рисунки, бинарные артефакты и устаревшие скрипты установки патчей. Упоминания 5G в GUI удалены.

Проверки исполнения и результатов необходимо проводить в своей среде; перенос файлов сам по себе не подтверждает повторения ранее опубликованных метрик.
